# AD5452 function reference

Source: `src/libs/AD5452/` (written for this project; no Arduino library existed).
Drives the Analog Devices AD5452 12-bit multiplying DAC over SPI. Datasheet:
AD5450/AD5451/AD5452 Rev. 0.

The chip scales the voltage on its VREF pin by `code / 4096`, with an op-amp on
IOUT1/RFB turning the current into a voltage: `Vout = -VREF × code / 4096`. It
only attenuates, it never amplifies. VREF can be up to ±10 V.

## Public API

| Call | Returns | Description |
|---|---|---|
| `AD5452(uint8_t syncPin, SPIClass* spi = &SPI, uint32_t spiHz = 8000000)` | n/a | Stores the pins. Nothing touches the hardware yet. |
| `begin()` | `void` | Sets SYNC as an output, idle HIGH. **Does not start the SPI bus**; `FunctionGenerator::begin()` does that. |
| `write(uint16_t code)` | `void` | Loads and updates the DAC. Codes above 4095 are clamped. |
| `code()` | `uint16_t` | Last code written (0 before the first write, same as the chip's power-on state). The chip has no readback. |
| `MAX_CODE` | `4095` | Full scale. |
| `DEFAULT_SPI_HZ` | `8000000` | The chip allows up to 50 MHz; `config.h` sets `MDAC_SPI_HZ`. |

## SPI details

One 16-bit word per write, MSB first, inside one SYNC-low frame:

```
C1 C0 D11 D10 D9 D8 D7 D6 D5 D4 D3 D2 D1 D0 X X
```

- `C1 C0 = 00`: load and update (power-on default). The driver always sends 00.
- `C1 C0 = 11` would move data clocking to the rising SCLK edge and leave the DAC inoperative until the next frame. The driver never sends it.
- The two LSBs are ignored, so the driver sends `code << 2`.

Data is clocked in on the falling SCLK edge and latched when SYNC goes high. The
driver uses `SPI_MODE1` (the datasheet's own interfacing example). Each write sets
its own `SPISettings`, so the chip can share the generator bus with the AD9833
(which uses `SPI_MODE2`).

## Gotchas

- **Power-on state is zero scale (code 0).** For the amplitude DAC that's 0 V, which is safe. For the offset DAC code 0 is one end of the offset range (`OFFSET_V_AT_CODE_0`), so the output sits there until `FunctionGenerator::begin()` writes the 0 V code. Keep `begin()` early in `setup()`.
- **Floating SYNC before `setup()`.** Until `begin()` runs, the SYNC pins float. A 10 kΩ pull-up on each SYNC line keeps the chip deselected during boot.
- **Decoupling.** One 100 nF capacitor from VDD to GND, as close to the chip as the adapter board allows.
- **Phase compensation.** The datasheet suggests 1–2 pF across RFB (in parallel with the internal feedback resistor) if the I/V op-amp rings.
- **MSOP-8 package.** It needs an MSOP-to-DIP adapter for a breadboard.

## Typical use

```cpp
AD5452 dac(PIN_AMP_DAC_CS, &SPI, MDAC_SPI_HZ);
SPI.begin(PIN_GEN_SCK, PIN_GEN_MISO, PIN_GEN_MOSI);
dac.begin();
dac.write(2048);         // about half of VREF
uint16_t now = dac.code();
```
