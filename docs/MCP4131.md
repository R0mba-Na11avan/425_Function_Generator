# MCP4131 function reference

Source: `MCP4131.h` / `MCP4131.cpp` (Derek Duncan, 2018).
Drives the Microchip MCP4131 single digital potentiometer over SPI.

## Public API

| Call | Returns | Description |
|---|---|---|
| `MCP4131(int slave_select_pin)` | n/a | Calls `SPI.begin()` and sets the select pin to `OUTPUT`. There is no separate `begin()`. |
| `readWiper()` | `byte` | Reads the current wiper position. |
| `writeWiper(unsigned int wiperValue)` | `void` | Sets the wiper position. Only the low byte is sent, and the MCP4131 is a 7-bit part, so use 0..128. |
| `incrementWiper()` | `void` | Moves the wiper up one step. |
| `decrementWiper()` | `void` | Moves the wiper down one step. |

## SPI details

Each transaction uses 250 kHz, MSBFIRST, `SPI_MODE0` on the global `SPI` object. The chip-select pin is driven LOW for the transfer, then HIGH.

A transfer is a command byte (`address << 4 | command << 2`) followed by one data byte for read and write. Increment and decrement send the command byte only.

## Private members

| Member | Purpose |
|---|---|
| `ADDRESS_WIPER0` / `ADDRESS_WIPER1` | Register addresses. Only wiper 0 is used. |
| `COMMAND_WRITE` / `READ` / `INCREMENT` / `DECREMENT` | Command bits `B00` / `B11` / `B01` / `B10`. |
| `sendCommand(address, command, data)` | Two-byte transfer, returns the second byte clocked back. |
| `sendCommand(address, command)` | One-byte transfer. |
| `enableChip()` / `disableChip()` | Drive the select pin LOW / HIGH. |
| `checkIfError(byte)` | Declared but never defined. Don't call it. |

## Gotchas

- **Only one instance works.** The select pin is stored in a file-level global (`slaveSelectPin` in `MCP4131.cpp`), not a class member. A second `MCP4131` overwrites it, and both objects then talk to the last pin given.
- **Hardwired SPI bus.** It always uses the default `SPI` object, so there is no way to pass in another bus.
- **No range check.** `writeWiper()` truncates to a byte and doesn't clamp to the 7-bit range.

## Typical use

```cpp
MCP4131 pot(9);     // CS on pin 9
pot.writeWiper(64); // roughly mid-scale
byte now = pot.readWiper();
```
