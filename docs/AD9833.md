# AD9833 function reference

Source: `src/libs/AD9833/` (Rob Tillaart, v0.4.5, MIT).
Drives the Analog Devices AD9833 DDS waveform generator over SPI. Default crystal is 25 MHz.

## Constructors

| Call | Description |
|---|---|
| `AD9833(uint8_t slaveSelect, __SPI_CLASS__ * mySPI = &SPI)` | Hardware SPI. `slaveSelect` is the FSYNC pin. |
| `AD9833(uint8_t slaveSelect, uint8_t spiData, uint8_t spiClock)` | Software (bit-banged) SPI. |

Passing `slaveSelect = 255` disables chip-select handling (for a chip whose FSYNC is tied low).
Constructors only store the pins. Nothing touches the hardware until `begin()`.

## Setup and reset

| Call | Returns | Description |
|---|---|---|
| `begin()` | `void` | Configures pins, sets SPI to 8 MHz / MSBFIRST / MODE2, then calls `reset()`. **Does not call `SPI.begin()`** for hardware SPI (that line is commented out), so call it yourself. Resets the SPI speed to 8 MHz, so call `setSPIspeed()` *after* `begin()`. |
| `reset()` | `void` | `hardwareReset()`, then writes the control register with `B28` set (sine output). |
| `hardwareReset()` | `void` | Despite the name, no pin is involved. It sets the `RESET` bit in the control register and clears the library's cached state (control, waveform, frequencies, phases). |

## Waveform and power

| Call | Returns | Description |
|---|---|---|
| `setWave(uint8_t waveform = AD9833_OFF)` | `void` | Selects the output. Values above `AD9833_TRIANGLE` are silently ignored. Clears the sleep bits, so it also wakes the chip from `setPowerMode()`. |
| `getWave()` | `uint8_t` | Cached waveform (`AD9833_*`). |
| `setPowerMode(uint8_t mode = 0)` | `bool` | `false` if `mode > 3`. Otherwise writes the sleep bits (control bits 7:6). |
| `getPowerMode()` | `uint8_t` | Cached power mode, 0..3. |

Waveform constants:

| Constant | Value | Output | Control bits set |
|---|---|---|---|
| `AD9833_OFF` | 0 | DAC and clock disabled | `SLEEP1 \| SLEEP12` |
| `AD9833_SINE` | 1 | Sine | none |
| `AD9833_SQUARE1` | 2 | Square (MSB) | `DIV2 \| OPBITEN` |
| `AD9833_SQUARE2` | 3 | Square (MSB/2), per datasheet half the frequency of `SQUARE1` | `OPBITEN` |
| `AD9833_TRIANGLE` | 4 | Triangle | `MODE` |

Power constants: `AD9833_PWR_ON` (0), `AD9833_PWR_DISABLE_DAC` (1), `AD9833_PWR_DISABLE_CLOCK` (2), `AD9833_PWR_DISABLE_ALL` (3).

## Frequency

| Call | Returns | Description |
|---|---|---|
| `setFrequency(float frequency, uint8_t channel = 0)` | `float` | Clamps to 0..`AD9833_MAX_FREQ` and writes the 28-bit frequency register for `channel` (0 or 1). Returns the clamped value, or `-1` if `channel > 1`. It does **not** switch the active channel. |
| `getFrequency(uint8_t channel = 0)` | `float` | Cached value in Hz. No bounds check on `channel`. |
| `getMaxFrequency()` | `float` | `AD9833_MAX_FREQ` (12.5 MHz). |
| `setFrequencyChannel(uint8_t channel)` | `void` | Selects which frequency register drives the output (`FSELECT`). Ignored if `channel > 1`. |
| `setUseRounding(bool flag = true)` | `void` | Round (default) or truncate when converting Hz to the register value. |
| `getUseRounding()` | `bool` | Current rounding flag. |

Resolution is crystal / 2^28, about 0.093 Hz with a 25 MHz crystal. The returned and cached frequency is the requested value, not the quantised one the chip produces.

## Phase

| Call | Returns | Description |
|---|---|---|
| `setPhase(float phase, uint8_t channel = 0)` | `float` | Phase in degrees, wrapped into [0, 360). Returns the wrapped value, or `-1` if `channel > 1`. 12-bit register. |
| `getPhase(uint8_t channel = 0)` | `float` | Cached phase in degrees. |
| `getMaxPhase()` | `float` | `AD9833_MAX_PHASE` (360.0). |
| `setPhaseChannel(uint8_t channel)` | `void` | Selects the active phase register (`PSELECT`). Ignored if `channel > 1`. |
| `setPhaseRadians(float phase, uint8_t channel = 0)` | `float` | Radian wrapper around `setPhase()`. |
| `getPhaseRadians(uint8_t channel = 0)` | `float` | Cached phase in radians. |

## SPI

| Call | Returns | Description |
|---|---|---|
| `setSPIspeed(uint32_t speed)` | `void` | Hardware SPI clock in Hz (default 8 MHz). |
| `getSPIspeed()` | `uint32_t` | Current speed setting. |
| `usesHWSPI()` | `bool` | `true` for hardware SPI, `false` for software SPI. |

## Crystal (experimental)

| Call | Returns | Description |
|---|---|---|
| `setCrystalFrequency(float crystalFrequency = 25000000)` | `void` | Use if your module's oscillator isn't 25 MHz. Only changes the Hz-to-register factor. `AD9833_MAX_FREQ` stays 12.5 MHz. |
| `getCrystalFrequency()` | `float` | Current crystal setting. |

## Low-level API (expert use)

| Call | Returns | Description |
|---|---|---|
| `writeControlRegister(uint16_t value)` | `void` | Writes the low 14 bits to the chip. Does **not** update the cached control value. |
| `readControlRegisterCache()` | `uint16_t` | The library's cached control register. |
| `writeFrequencyRegister(uint8_t channel, uint32_t freq)` | `void` | Writes a raw 28-bit tuning word (sets `B28`). |
| `writePhaseRegister(uint8_t channel, uint16_t value)` | `void` | Writes a raw 12-bit phase word. |
| `writeFrequencyRegisterLSB(uint8_t channel, uint16_t LSB)` | `void` | Experimental. Writes the low 14 bits only (clears `B28` and `HLB`). |
| `writeFrequencyRegisterMSB(uint8_t channel, uint16_t MSB)` | `void` | Experimental. Writes the high 14 bits only (clears `B28`, sets `HLB`). |

## Constants

`AD9833_MAX_FREQ` (12500000UL), `AD9833_MAX_PHASE` (360.0).
Error codes (`AD9833_OK`, `AD9833_ERR_*`) are defined but not returned by the library yet.
Control register bits: `AD9833_B28`, `HLB`, `FSELECT`, `PSELECT`, `RESET`, `SLEEP1`, `SLEEP12`, `OPBITEN`, `DIV2`, `MODE`.

## Typical use

```cpp
AD9833 gen(10);          // FSYNC on pin 10, hardware SPI
SPI.begin();
gen.begin();
gen.setWave(AD9833_SINE);
gen.setFrequency(1000);  // 1 kHz on channel 0
```
